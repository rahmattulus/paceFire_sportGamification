# PaceFire Redesign Notes

## Visual Direction

Tampilan PaceFire diselaraskan dengan referensi Headspace:

- Canvas Butter Cream `#FFF7E7`
- Aksi utama Marigold `#FF6B35`
- Accent Butter `#FFD25C`
- Accent Sage `#7E9F4B`
- Text Ink Brown `#2E1A47`
- Secondary Ink `#594675`
- Warm surface `#FBF1DA`
- Warm divider `#E8DFC9`

## Updated Components

- Logo PaceFire SVG kustom pada header.
- Hero beranda bergaya Aurora gradient.
- Card, panel, form, leaderboard, route, challenge, dan badge menggunakan sudut soft 24px.
- Tombol utama berbentuk pill Marigold dengan warm glow.
- Streak ring berbasis conic-gradient dan animasi reveal.
- Grafik canvas menggunakan warna Headspace.
- Bottom tab bar mobile untuk pengguna.
- Top navigation responsif untuk tablet dan desktop.
- Animasi breathe pada hero dan sphere visual.
- Floating lembut pada companion illustration.
- Reduced-motion support untuk preferensi aksesibilitas.

## Responsive Rules

- Mobile: header ringkas, bottom tab 5 menu, konten satu kolom.
- Tablet: top navigation, grid route/challenge dua kolom.
- Desktop: container maksimal 1200px, grid dashboard tiga kolom dan grid route tiga kolom.
- Semua kontrol utama mempertahankan touch target minimal 48px.
